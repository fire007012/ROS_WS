# 四轮底盘实机测试（2026-10-08）

四个电机单独转动、两组正反向、四轮同时正反转，共 10 项测试全部通过。
实际连接四个底盘电机，第五路未接入。未修改或烧录 STM32 固件。

## 测试方式

通过 `/motor_velocity_cmd` 向实际 `can_interface_node` 发送目标，经 can0、STM32 CAN1
命令解析、CAN2 驱动电机。can0 使用标准命令帧、500 kbps。
每项目标为 ±10 RPM，持续约 1 秒，随后发送零目标，确认四轮停车再进入下一项。

以下向量均按逻辑轮序 `[前, 右, 后, 左]`，对应 CAN2 地址 `[2, 1, 4, 3]`、
STM32 索引 `[1, 0, 3, 2]`。速度来自驱动器原生 `0x35` 实时回包。

| 测试 | 目标速度（RPM） | 实测带符号峰值（RPM） | 结果 |
| --- | --- | --- | --- |
| 地址 2 单独转动 | `[10, 0, 0, 0]` | `[10.9, 0, 0, 0]` | 通过 |
| 地址 1 单独转动 | `[0, 10, 0, 0]` | `[0, 10.7, 0, 0]` | 通过 |
| 地址 4 单独转动 | `[0, 0, 10, 0]` | `[0, 0, 10.3, 0]` | 通过 |
| 地址 3 单独转动 | `[0, 0, 0, 10]` | `[0, 0, 0, 10.3]` | 通过 |
| X 组前进 | `[10, 0, -10, 0]` | `[11.2, 0, -10.5, 0]` | 通过 |
| X 组后退 | `[-10, 0, 10, 0]` | `[-12.1, 0, 10.9, 0]` | 通过 |
| Y 组正向 | `[0, 10, 0, -10]` | `[0, 10.3, 0, -10.6]` | 通过 |
| Y 组反向 | `[0, -10, 0, 10]` | `[0, -11.1, 0, 10.4]` | 通过 |
| 四轮同时正转 | `[10, 10, 10, 10]` | `[9.7, 9.6, 9.3, 9.7]` | 通过 |
| 四轮同时反转 | `[-10, -10, -10, -10]` | `[-10.7, -9.6, -10.3, -9.6]` | 通过 |

每阶段检查运动轮方向正确、有真实 F6 运动 ACK，未参与轮速度不超过 1.5 RPM；
运动过程中要求链路就绪、真实反馈未过期、无急停。
阶段间要求四轮均收到停车后的新速度回包，且绝对速度不超过 1 RPM 持续至少 0.5 秒。
测试结束再次发送零目标和软件急停，最终反馈 `[0.0, 0.2, 0.1, 0.0]` RPM，
已确认停车；测试节点和本次 ROS master 均已退出。
日志无运动 ACK 超时、负 ACK 或应用层发送失败；最终软件急停为预期操作。

## CAN 稳定性观察

| 控制器累计计数 | 测试前 | 测试后 | 增量 |
| --- | --- | --- | --- |
| error-warning | 278 | 350 | 72 |
| error-passive | 19 | 25 | 6 |
| bus-off | 0 | 0 | 0 |
| restarts | 0 | 0 | 0 |

结束时 can0 状态为 ERROR-ACTIVE，内核 RX/TX errors 和 TX dropped 为 0。
历史 RX dropped 为 15016，本轮未增加。虽然运动测试通过，控制器告警/被动错误计数仍增长，
CAN 连接稳定性需要后续排查，不能据此认定总线无错误。
