# 预设路径与动态绕障

没有激光雷达时，默认航点模式现已支持四路 VL53 横移绕行，见
[四路测距航点绕行](四路测距航点绕行.md)。它使用测距和里程计完成局部绕行，
遇到无法确认净空的情况停车，不需要下面的激光地图导航栈。

以下是有二维激光雷达时的地图导航模式。
固定路线模式由 `path_tracker_node` 跟踪 YAML 点位；关闭 `enable_range_avoidance`
时仅保留原防撞停车。
带随机障碍物时使用动态导航：YAML 路径仍是任务的预设路线，但
`move_base_path_adapter_node` 会把每个点依次发送给 `move_base`。`TEB` 根据
`/scan` 代价地图绕过临时障碍，成功到达当前点后才继续下一点。

启动完整任务的动态模式：

```bash
roslaunch robot_navigation mission_complete.launch \
  use_dynamic_navigation:=true \
  dynamic_map_file:=/absolute/path/to/arena.yaml
```

只启动底盘与动态导航测试：

```bash
roslaunch robot_navigation dynamic_navigation.launch \
  map_file:=/absolute/path/to/arena.yaml \
  enable_range_safety:=true
```

前置条件：

- 已安装 `move_base`、`amcl`、`global_planner`、`teb_local_planner` 和 `map_server`。
- 有静态场地图，且 `/scan` 是标定到 `base_link` 的二维激光数据。
- TF 链完整：`map -> odom -> base_link`。AMCL 提供 `map -> odom`，底盘里程计提供 `odom -> base_link`。
- 为前、左、右、后 VL53L1X 设置真实的安装位姿；默认平移占位值不能用于现场。后方 CAN sensor_id=5，发布 `/rear/range`，用于倒车和转弯保护。

速度路径始终为：

```text
move_base -> /cmd_vel_external -> cmd_vel_mux -> /cmd_vel_muxed -> planner_node
```

在激光地图导航模式中，VL53L1X 作为近距离失效即停层，绕行由 TEB 完成；
航点跟踪器的四路测距绕行不会同时运行。传感器超时或距离不足时会持续占用
`/cmd_vel_safety`，直到风险解除。请在实车上测量制动减速度和总延迟，并更新
`braking_deceleration_mps2`、`reaction_time_sec`、`stop_margin_mm`。
