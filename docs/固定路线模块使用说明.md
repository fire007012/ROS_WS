# 固定路线模块使用说明

`fixed_route_runner_node` 按 YAML 中的速度段运行，输出到 `/cmd_vel_fixed_route`，
经过 `cmd_vel_mux` → `/cmd_vel_muxed` → `planner_node` → `/motor_velocity_cmd`。
医疗任务的航点路线见[医疗送药航点路径规划](医疗送药航点路径规划.md)。

默认配置：[fixed_route.yaml](../robot_bringup/config/fixed_route.yaml)。
速度单位为 m/s，角速度单位为 rad/s，持续时间单位为秒。

```yaml
publish_rate_hz: 20.0
start_delay_sec: 1.0
loop_route: false
auto_start: false
stop_between_segments: true
publish_zero_when_paused: true

route:
  - name: forward
    vx: 0.03
    vy: 0.0
    omega: 0.0
    duration: 2.0
  - name: stop_hold
    vx: 0.0
    vy: 0.0
    omega: 0.0
    duration: 1.0
```

段还支持 `target_distance`（米）和 `target_heading`（弧度），使用里程计判断段完成。
`auto_start` 控制速度段调度，不替代 CAN 节点的物理启动联锁。
仓库默认配置为 `auto_start: true`，启动前应检查配置；上述示例关闭自动调度。

在已配置好 CAN、反馈和启动条件的工作空间中启动：

```bash
roslaunch robot_navigation complete_navigation.launch \
  enable_teleop:=false \
  enable_fixed_route:=true \
  fixed_route_file:=/absolute/path/to/route.yaml
```

控制话题 `/fixed_route/control` 类型为 `std_msgs/String`，支持
`start`、`restart`、`pause`、`resume`、`stop`。
`/fixed_route/hold` 为 `std_msgs/Bool`，用于其他进程临时挂起与释放路线。

```bash
rostopic pub -1 /fixed_route/control std_msgs/String "data: 'pause'"
rostopic pub -1 /fixed_route/control std_msgs/String "data: 'resume'"
rostopic echo /fixed_route/status
rostopic echo /fixed_route/current_segment
rostopic echo /cmd_vel_fixed_route
rostopic echo /motor_velocity_cmd
```

状态还包括 `/fixed_route/is_running`、`/fixed_route/is_paused` 和
`/fixed_route/external_hold_active`，均为 `std_msgs/Bool`。
